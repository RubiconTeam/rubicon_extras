# Rubicon Extras

Extra utilities for Rubicon like interpolated camera, camera beat bumper, dancers and UI elements. [Rubicon](https://github.com/RubiconTeam/rubicon) is necessary to use this submodule.

## Installing
This repository is installed the same way as Rubicon. You can either add it to your repository as a submodule (recommended, as you can keep it updated this way), or directly clone the repository into your `res://addons/` folder.

To add the submodule to your project, open a terminal, cmd, powershell or git bash in your project location and run this command:
```
git submodule add --name rubicon_extras https://github.com/RubiconTeam/rubicon_extras addons/rubicon_extras || git submodule update --init --recursive --remote
```

## Usage
This repository only contains classes and does not have a `plugin.cfg`, therefore you don't need to enable the plugin and you can directly use the classes when adding a node into your scene.
